# СДВИГ: 48 ЧАСОВ · v0.1

Оригинальная 2D RPG-стратегия про подпольную организацию, действующую в двух мирах. **Не 3D и не линейный текстовый квест.**

## Первый игровой цикл

1. Во Внешнем мире подготовь агента и запусти переход.
2. Во Внутреннем мире выбери один из шести районов, выполни операции (всего 12), рискуя временем и обнаружением.
3. Вернись с добычей. Продавай материалы, оставляй часть для строительства.
4. Построй лабораторию, исследуй улучшения, нанимай новых агентов, повторяй.

- 3 агента: разведчица Лея, инженер Норд, посредник Рей.
- 3 типа навыков: скрытность, техника, переговоры.
- Ресурсы: кредиты, сплавы, данные, модули, разведданные.
- Успех миссий зависит от специализации, усталости, уровня подозрения и исследований.
- 3 улучшения базы, 3 научных проекта, 1 слот автосохранения.
- Шесть районов и двенадцать операций, на каждом цикле игрок выбирает свой путь.

## Играть на ПК

Открой папку shift48 как проект в Godot 4.5.2 Standard и запусти F5.

## APK для Android

Перейди на GitHub Actions → **Shift48 Android APK** → последний успешный запуск → Artifacts → Shift48-v0.1-Android. APK отладочный, подписан временным ключом. Имя пакета **org.warfwar.shift48**; игра устанавливается отдельно от «Номенклатуры ночи».

## Проверка

Из папки shift48:

    godot --headless --editor --path . --quit
    godot --headless --path . --script res://tests/smoke.gd
    godot --headless --path . --quit-after 12

Пока не реализованы картинки персонажей, иллюстрации миссий и звук: приоритет первой версии — игровой баланс, ресурсы и развитие. Внешний мир и Внутренний мир оригинальные, без использования защищённых персонажей ранобэ.

## Версия 0.2 — интерфейс Android

Исправлена прокрутка: один ScrollContainer на активный экран, сохранение позиции списка после действия, независимая позиция у каждой вкладки; удалена длинная общая страница с вложенными блоками. Кнопки с достаточной высотой для нажатия пальцем.

Постоянные вкладки: **Обзор, Районы, Миссии, Штаб, Агенты**. Штаб открывает самостоятельные экраны **Склад, Рынок, Строительство, Исследования**; журнал доступен из Обзора. Из подпунктов работает возврат в Штаб.

Игра сохраняет те же ресурсы, баланс и файл `user://shift48_v01.json`: прогресс v0.1 совместим с v0.2 при установке поверх старой версии, package ID `org.warfwar.shift48` не изменён. Если тестовые APK имеют разные debug-ключи, обновление может потребовать удаления предыдущей сборки с потерей локальных сохранений — это ограничение тестовой подписи.

Проверка UI: `godot --headless --path . --script res://tests/ui_smoke.gd`.
